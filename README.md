# 반짝 단어카드

아이들과 엄마가 같이 쓰는 단어장 앱입니다. 설치형 웹앱(PWA)이라 Chrome에서 "홈 화면에 추가 / 앱 설치"로 설치합니다.
빌드 과정은 없고, 이 폴더를 그대로 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 됩니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| 🔍 찾기 | 영어·국어·한자 검색(자동 판별). 영어는 발음·영영 뜻풀이·예문·한국어 뜻 후보, 국어는 뜻풀이·한자, 한자는 글자별 훈음과 읽기. 뜻을 골라 ★를 누르면 별 단어장에 들어갑니다. |
| ⭐ 단어장 | 별 단어 / 오답노트(자주 틀린 순) / 찾은 기록. 직접 넣기(여러 개 한꺼번에 `단어 = 뜻`), 단어 나누기 코드 |
| 🃏 테스트 | 범위: 내 별 단어 전체 또는 엄마 세트 하나, 언어(모두/영어/국어/한자). 🎯 뜻 고르기(4지선다) · 👂 듣고 고르기(단어는 숨기고 소리만) · 🃏 말하고 넘기기(눌러 뒤집고 좌우로 밀기) · ⚡ 반짝 플래시(자동 넘김). 영어를 읽어 주고, 💡 힌트는 그 단어가 들어간 사전 예문을 보여 주고 읽어 줍니다. |
| 🌸 나 | 아바타, 곧 열리는 꾸미기, 성장 숫자, 최근 7일 그래프, 내가 만든 문장, 단어 정원, 설정 |
| 📚 엄마 세트 (단어장 탭) | 엄마가 만든 단어 묶음. 📷 단어장 사진(AI 또는 무료 글자 인식) · 📋 글 붙여넣기 · ✏️ 직접 → 영어/국어/한자로 자동 분류 → 확인 화면에서 고치고 저장 → QR로 아이 기기에 보내기. 아이 기기에서 "📊 엄마에게 결과 보여주기" QR을 엄마가 찍으면 아이별 진도가 보입니다. |
| 🎤 말로 문장 만들기 | 단어를 넣어 문장을 말하면(브라우저 음성 인식) AI 선생님이 별점, 칭찬, 고친 문장(달라진 낱말 표시), 더 좋은 표현, 해석, 팁을 알려 주고 읽어 줍니다. "따라 말하기"로 더 좋은 표현을 따라 해 봅니다. AI가 꺼져 있으면 단어를 넣어 말했는지만 확인합니다. |

## 과목 나누기

단어장·테스트·정원·문장 만들기 위에 `🔤 영어 / 📖 국어 / 漢 한자 / 🔀 섞어서` 막대가 있습니다. 고른 과목만 보이고 테스트에도 그 과목만 나옵니다. 4지선다 보기도 같은 과목의 뜻에서만 고릅니다. 사진에서 여러 과목이 나오면 저장할 때 과목별 세트로 나눕니다(끌 수 있음). `섞어서`는 익숙해진 뒤 한꺼번에 복습할 때 씁니다.

## 성장 규칙

- 단어마다 0~5단계: 씨앗 → 새싹 → 잎새 → 꽃봉오리 → 꽃 → 반짝 별꽃
- 힌트 없이 맞힘: 한 단계 자람 / 힌트 보고 맞힘: 그대로 / 틀림: 0단계(3단계 이상이면 두 단계 아래로)
- 다음 복습까지 0·1·2·4·8·16일. 틀린 단어는 같은 테스트에서 3장 뒤에 최대 2번 다시 나옵니다.
- 출제 가중치: 처음 보는 단어, 복습 날짜가 된 단어, `(틀림×2 + 힌트) / 본 횟수`가 클수록, 직전에 틀린 단어일수록 높습니다.
- 오답노트: 틀린 적이 있고 아직 3단계 미만인 단어. 3단계가 되면 "이겨낸 단어"로 졸업합니다.
- 꾸미기 아이템은 포인트로 사지 않고, 성장(꽃 핀 단어, 혼자 맞힌 수, 이겨낸 단어, 연속 공부일 등)에 따라 열립니다. 한 번 열리면 닫히지 않습니다.

- 문장 만들기: 힌트 없이 단어를 바르게 넣은 문장을 만들면 그 단어가 하루 한 번 한 단계 자랍니다.

## AI 선생님 (Claude API)

- 엄마 설정(비밀번호)에서 Anthropic API 키를 넣으면 켜집니다. 모델은 일마다 따로 정합니다: 🎤 문장 확인(자주 씀) 기본 `claude-haiku-5-5`, 📷 사진 읽기(가끔 씀) 기본 `claude-opus-5-5`. 엄마 설정에서 Opus 5.5 / Sonnet 5.5 / Haiku 5.5 중에서 바꿀 수 있고, 목록에 1번 쓸 때 어림 요금이 나옵니다.
- 비용 관리: 응답의 `usage`로 이 기기의 이번 달 사용액을 어림해 보여 주고, 한 달 한도(기본 3달러)에 닿으면 AI를 멈춥니다. 요금표는 `js/ai.js`의 `PRICE`(100만 토큰당 달러), 환율은 1달러=1,400원으로 어림합니다. 정확한 금액은 platform.claude.com 사용량 화면에서 확인하세요.
- 공식 SDK `@anthropic-ai/sdk`를 브라우저용으로 묶어(`js/vendor/anthropic-sdk.min.js`) 처음 쓸 때만 불러오고, `dangerouslyAllowBrowser: true`로 기기에서 바로 부릅니다. 그래서 키가 그 기기에 저장됩니다. **이 앱 전용 키를 만들고 사용 한도를 정해 두세요.**
- 요청: `client.beta.messages.create` + `output_config.format`(JSON 스키마)로 정해진 모양의 답을 받습니다. 안전 검사로 거절되면 서버가 다른 모델로 다시 시도하도록 Opus·Sonnet 요청에는 `fallbacks: "default"`(베타 `server-side-fallback-2026-07-01`)를 켰습니다. Haiku 5.5는 서버 쪽 대체 모델을 지원하지 않아 보내지 않습니다. 사진 읽기는 effort `medium`, 문장 확인은 `low`.
- 아이 기기로 옮기기: 엄마 설정 → "📲 아이 기기로 옮기기 (QR)" → 아이 기기에서 📷 QR로 받기.
- 키·비밀번호는 백업 코드와 단어 나누기 코드에 들어가지 않습니다.
- 공개 저장소에는 키가 없습니다. 키는 엄마가 입력한 기기(그리고 QR로 옮긴 기기)의 브라우저 저장소에만 있고, 다른 사람이 이 앱 주소를 열어도 그 사람 브라우저에는 키가 없습니다.
- 앱 한도는 이 앱의 요청만 막습니다. 키가 새어 나가는 경우에 대비해 Anthropic 콘솔에서 이 앱 전용 키를 쓰고 사용 한도를 정해 두세요. 기기를 잃어버리면 콘솔에서 그 키를 지우고 새 키를 넣습니다.
- 받은 코드(결과·백업)의 아바타 값은 앱의 아이템 목록에 있는 값만 쓰도록 거릅니다(`cleanAvatar`).

## 저장

모든 기록은 각 기기의 `localStorage`(`bwc.data.v1`)에만 저장됩니다. 서버로 보내는 개인 기록은 없습니다.
기기 사이 옮기기는 `💾 백업·되살리기`(BWB1 코드), 단어 목록 보내기는 `💌 단어 나누기`(BWW1 코드 또는 `#add=` 링크)를 씁니다.

## 사전 출처

- 영어: Free Dictionary API — https://dictionaryapi.dev
- 영→한 뜻·예문 해석: MyMemory 번역 API — https://mymemory.translated.net/doc/spec.php (기계 번역)
- 국어·한자: 위키낱말사전 https://ko.wiktionary.org, https://en.wiktionary.org (MediaWiki API, CC BY-SA)
- 한자 8급 50자: 한국어문회 한자능력검정시험 8급 배정한자 (앱 안에 포함, `js/data.js`)
- 영어 읽기·말하기 인식: 기기의 Web Speech API (Chrome의 음성 인식은 Google 서버에서 처리)
- AI 선생님: Anthropic Claude API (`js/ai.js`)
- 무료 글자 인식: Tesseract.js 5.1.1 (cdn.jsdelivr.net에서 필요할 때 불러옴)
- QR: qrcode-generator 2.0.4(MIT), jsQR 1.4.0(Apache-2.0) — `js/vendor/README.md`

## 패밀리 링크에서 쓰기

1. 이 폴더를 공개 주소에 올립니다(아래 "배포").
2. 보호자 Family Link 앱 → 아이 → 콘텐츠 제한 → Google Chrome → "승인된 사이트만 허용"에 앱 주소를 넣습니다.
3. 아이 기기 Chrome에서 주소를 열고 메뉴 → "앱 설치"(또는 "홈 화면에 추가").
4. 앱의 `나 → ⚙️ 설정 → 🔌 사전 연결 점검`에서 ❌가 나오면, 그 주소(`api.dictionaryapi.dev`, `api.mymemory.translated.net`, `ko.wiktionary.org`, `en.wiktionary.org`, AI를 쓰면 `api.anthropic.com`)도 승인된 사이트에 넣어 봅니다.
5. 세트 받기·결과 보내기용 QR 스캔에는 카메라 권한이 필요합니다. 카메라가 막혀 있으면 링크나 코드를 붙여 넣어도 됩니다.

## 배포

- GitHub Pages: 공개 저장소 `nami4K/mommy`의 `main` 브랜치 루트에 이 폴더 내용을 올립니다. Settings → Pages → Deploy from a branch → `main` / `(root)` → 주소 `https://nami4k.github.io/mommy/`.
- Netlify Drop(https://app.netlify.com/drop)에 폴더를 끌어다 놓아도 됩니다.
- 코드를 바꾸면 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 파일을 받습니다(한 번 더 열 때 반영).
