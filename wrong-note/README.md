# 다시봄 오답노트

초등 아이들의 틀린 문제를 **다른 날 다시 만나게** 하고, 다시 맞히면 꽃으로 피우는 가족 오답노트입니다.
설치형 웹앱(PWA)이라 갤럭시 탭의 Chrome에서 "앱 설치(홈 화면에 추가)"로 설치합니다.
주소: `https://nami4k.github.io/mommy/wrong-note/`

## 누가 무엇을 하나요

| | 엄마 | 아이 |
| --- | --- | --- |
| 들어가기 | 엄마 비밀번호 | 가족 코드를 한 번 넣고 이름 고르기 |
| 문제 넣기 | 문제집 쪽·번호 / 사진(자르기·연필 지우기·지우개) / 직접 쓰기 | 틀린 문제 사진 보내기 → 엄마가 확인해야 등록 |
| 풀기 | 아이 화면 미리 보기 | 오늘 문제 골라 풀기 → 채점 → 정답·풀이 보기 |
| 그 밖에 | 확인 대기, 문제 목록, 기록, 깜짝 카드, 설정 | 내 정원, 자라는 나, 테마 색 고르기 |

## 다시 풀기 규칙 (엄마 설정에서 바꿀 수 있음)

- 문제를 넣은 다음 날부터 나옵니다. 하루 최대 5문제(더 풀고 싶으면 "더 풀어 볼래?").
- 틀리면 같은 날에는 다시 나오지 않고 **다음 날** 다시 나옵니다. 문제마다 "N번 틀림"이 보입니다.
- 한 번만 틀렸던 문제는 다시 맞히면 **졸업**(꽃).
- 2번 이상 틀린 문제는 **단골 문제**: 다시 맞힌 뒤 **3 → 7 → 14 → 30일** 뒤에 다시 나오고, 모두 맞히면 졸업. 중간에 틀리면 다음 날부터 다시.
- 단골 문제가 먼저, 오래 기다린 문제가 먼저 나옵니다. 아이는 그중에서 풀 순서를 고릅니다.
- 채점: 띄어쓰기·마침표는 무시, 숫자가 같으면 단위(개, cm)는 안 써도 정답. 정답 칸에 `5개|다섯 개`처럼 여러 정답, `3, 5`처럼 여러 칸.
  그리기·잇기처럼 글로 쓰기 어려운 문제는 "스스로 확인"(정답을 보고 아이가 맞았어요/틀렸어요를 누름).

## 틀린 이유와 힌트

- 아이별 설정: 학년에 맞게(초1·2 안 쓰기, 초3·4 버튼으로 고르기, 초5부터 직접 쓰기) / 안 쓰기 / 버튼 / 쓰기.
- 적은 이유와 엄마 힌트는 풀 때 숨겨져 있다가 "힌트 보기"를 누르면 보입니다. 힌트를 본 풀이는 기록에 표시됩니다.

## 학년과 보관

- 학년은 입학한 해로 저장해서 **3월 1일**(설정에서 1월 1일로 변경 가능)에 저절로 올라갑니다.
- 등록하고 **2년** 지난 문제는 사진까지 자동으로 지웁니다. 30일 전부터 엄마 화면에 "삭제 예정"이 뜨고, "보관"에 체크하면 남습니다.
  지운 문제의 정복 숫자는 성장 기록에 남습니다.

## 보상

포인트나 물건 대신, 연구에서 내재적 동기와 덜 부딪히는 방식으로 만들었습니다.

- **내 정원**: 틀린 문제 = 씨앗, 다시 맞힘 = 새싹, 졸업 = 꽃.
- **자라는 나**: 처음엔 틀렸지만 이제 아는 문제 수, 이번 달과 지난달 비교, 힌트 없이 맞힌 비율, 단골 졸업 수, 강해진 단원, 이번 주 공부한 날. 형제끼리 비교하지 않고 연속 기록이 끊겨도 벌점이 없습니다.
- **칭찬 문구**: 노력과 방법을 칭찬("다시 풀어 본 덕분이야").
- **깜짝 카드**: 엄마가 예고 없이 가끔 보내는 칭찬 카드.
- **테마 고르기**: 아이가 직접 앱 색을 고릅니다(하늘·바다·숲·포도). 바탕은 차분한 색, 노랑은 기분 좋은 순간에만 씁니다. 틀림 표시는 빨강 대신 부드러운 주황입니다.

## 저장과 주고받기

- 모든 기록은 먼저 그 기기의 IndexedDB에 저장되어 인터넷이 없어도 됩니다.
- 가족 저장 공간(Supabase)이 연결되면 1분마다, 그리고 고칠 때마다 주고받습니다. 같은 문서는 나중에 고친 쪽이 남습니다.
  문제 내용(`problem`)과 아이의 풀이 기록(`progress`)은 따로 저장해서 엄마가 문제를 고치는 동안 아이 기록이 덮이지 않습니다.
- 서버 표는 직접 읽거나 쓸 수 없고, 가족 코드를 확인하는 함수(`wn_*`)로만 주고받습니다(`supabase.sql`).
  가족 코드를 아는 사람은 기록을 볼 수 있으니 가족끼리만 나누세요.

### 처음 연결

1. Supabase 프로젝트를 만들고 SQL Editor에서 `supabase.sql`을 한 번 실행합니다.
2. `config.js`에 Project URL과 Publishable 키(`sb_publishable_…`)를 넣습니다(공개돼도 되는 키). **Secret 키는 넣지 않습니다.**
3. 엄마 기기에서 앱을 열고 "처음 시작하기" → 가족 코드가 만들어집니다.
4. 아이 태블릿: 앱을 열고 "가족 코드로 들어가기"에 코드를 넣거나, 엄마 설정 화면의 QR을 태블릿 카메라로 찍습니다.

## 패밀리 링크

1. 보호자 Family Link 앱 → 아이 → 콘텐츠 제한 → Google Chrome → "승인된 사이트만 허용"에 `nami4k.github.io`를 넣습니다.
2. 연결이 안 되면 Supabase 주소(`○○○○.supabase.co`)와 글꼴 주소(`fonts.googleapis.com`, `fonts.gstatic.com`)도 넣어 봅니다.
3. 아이 태블릿 Chrome에서 주소를 열고 메뉴 → "앱 설치"(또는 "홈 화면에 추가").

## Claude 정리(하루 한두 번)

"Claude 정리 대기" 문제(문제 그림이나 정답이 빈 문제)를 Claude Code 예약 작업이 처리합니다.
문제집 PDF에서 그 쪽·번호를 깨끗하게 잘라 `img`에, 정답과 풀이를 `answer`·`solution`에 넣고 `status`를 `ready`로 바꿉니다.
문제집 목차가 있으면 `book.units`(단원별 쪽 범위)와 `book.pages`(쪽 번호 → 쪽 그림)도 채웁니다.
이 작업은 Secret 키로 `wn_docs`·`wn_images` 표에 직접 씁니다.
